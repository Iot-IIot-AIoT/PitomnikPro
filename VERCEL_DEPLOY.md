# 🚀 Деплой на Vercel

## ✅ Проблема решена - добавлен vercel.json

Ошибка 404 возникала из-за того, что Vercel не знал, как обрабатывать маршруты SPA (Single Page Application).

Добавлен файл `vercel.json` с правильными настройками:
- Все маршруты перенаправляются на `index.html`
- Настроено кэширование для статических файлов

---

## 📋 Инструкция по деплою

### Способ 1: Через Vercel CLI (рекомендуется)

1. **Установите Vercel CLI:**
```bash
npm install -g vercel
```

2. **Войдите в аккаунт:**
```bash
vercel login
```

3. **Задеплойте проект:**
```bash
vercel --prod
```

4. **Следуйте инструкциям в терминале:**
   - Выберите проект (или создайте новый)
   - Подтвердите настройки
   - Дождитесь завершения деплоя

5. **Получите ссылку:**
   После завершения вы получите ссылку вида: `https://ваш-проект.vercel.app`

---

### Способ 2: Через GitHub + Vercel Dashboard

1. **Загрузите код на GitHub:**
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ваш-username/ваш-репозиторий.git
git push -u origin main
```

2. **Подключите репозиторий к Vercel:**
   - Зайдите на https://vercel.com
   - Нажмите "New Project"
   - Выберите ваш репозиторий
   - Vercel автоматически определит настройки

3. **Настройки деплоя:**
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`

4. **Нажмите "Deploy"**

## 🔧 Проверка конфигурации

### Файл vercel.json должен содержать:

```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ],
  "headers": [
    {
      "source": "/assets/(.*)",
      "headers": [
        {
          "key": "Cache-Control",
          "value": "public, max-age=31536000, immutable"
        }
      ]
    }
  ]
}
```

Этот файл:
- ✅ Перенаправляет все маршруты на `index.html` (решает проблему 404)
- ✅ Настраивает кэширование для статических файлов (ускоряет загрузку)

## 🎯 После деплоя

### Проверьте:
1. ✅ Главная страница загружается
2. ✅ Навигация между разделами работает
3. ✅ Обновление страницы (F5) не вызывает 404
4. ✅ Прямые ссылки на разделы работают

### Если что-то не работает:

**Проблема:** 404 при обновлении страницы
**Решение:** Убедитесь, что файл `vercel.json` загружен в корень репозитория

**Проблема:** Не загружаются стили/скрипты
**Решение:** Проверьте, что папка `dist` создана командой `npm run build`

**Проблема:** Белый экран
**Решение:** Откройте консоль браузера (F12) и проверьте ошибки

## 📊 Оптимизация (опционально)

### Уменьшение размера бандла

Текущий размер: **808 KB** (можно уменьшить до ~300 KB)

**Вариант 1: Code Splitting**
Добавьте в `vite.config.js`:
```javascript
export default defineConfig({
  // ... существующий код
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['react', 'react-dom'],
          charts: ['recharts'],
        },
      },
    },
  },
});
```

**Вариант 2: Lazy Loading**
В `App.tsx` используйте динамические импорты:
```javascript
const Dashboard = lazy(() => import('./components/Dashboard'));
const PlantList = lazy(() => import('./components/PlantList'));
// и т.д.
```

## 🔐 Настройка домена (опционально)

### Подключить свой домен:

1. В Vercel Dashboard → ваш проект → Settings → Domains
2. Добавьте ваш домен (например: `pitomnik.ru`)
3. Следуйте инструкциям для настройки DNS
4. SSL сертификат будет настроен автоматически

---

## 📱 PWA (Progressive Web App)

Чтобы сделать приложение устанавливаемым на телефон:

1. Создайте файл `public/manifest.json`
2. Добавьте service worker
3. Добавьте мета-теги в `index.html`

(Это опционально, но улучшает UX на мобильных устройствах)

## 🆘 Поддержка

Если проблема 404 сохраняется:

1. **Проверьте логи Vercel:**
   - Dashboard → ваш проект → Deployments → выберите деплой → Logs

2. **Очистите кэш браузера:**
   - Ctrl+Shift+R (Windows/Linux)
   - Cmd+Shift+R (Mac)

3. **Пересоздайте деплой:**
```bash
vercel --prod --force
```
