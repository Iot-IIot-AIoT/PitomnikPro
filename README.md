## 🚀 Быстрый старт (фронтенд)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется на http://localhost:5173

### 3. Сборка для продакшена
```bash
npm run build
```
Готовые файлы будут в папке `dist/`

## 🌐 Деплой на хостинг

### Вариант 1: Vercel (рекомендуется)

1. Зарегистрируйтесь на https://vercel.com
2. Установите Vercel CLI:
```bash
npm install -g vercel
```

3. Задеплойте проект:
```bash
vercel
```

4. Следуйте инструкциям в терминале

**Результат:** Ваш сайт будет доступен по адресу `https://ваш-проект.vercel.app`

### Вариант 2: Netlify

1. Зарегистрируйтесь на https://netlify.com
2. Установите Netlify CLI:
```bash
npm install -g netlify-cli
```

3. Задеплойте:
```bash
npm run build
netlify deploy --prod --dir=dist
```

### Вариант 3: GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ваш-username/ваш-репозиторий.git
git push -u origin main
```

3. В настройках репозитория включите GitHub Pages
4. Выберите ветку `main` и папку `/dist`

### Вариант 4: Собственный сервер (VPS)

1. Арендуйте VPS (Timeweb, Beget, Reg.ru)
2. Установите Nginx:
```bash
sudo apt update
sudo apt install nginx
```

3. Скопируйте файлы из `dist/` на сервер:
```bash
scp -r dist/* user@your-server:/var/www/html/
```

4. Настройте Nginx (конфиг в файле `nginx.conf`)

## 💾 Хранение данных

**Текущая версия:** Данные хранятся в `localStorage` браузера

**Ограничения:**
- Данные привязаны к одному браузеру
- Нет синхронизации между устройствами
- При очистке кэша данные удаляются

**Для продакшена:** Настройте бэкенд с базой данных (см. `BACKEND_SETUP.md`)

## 📱 Использование

### CRM Система
1. Откройте раздел "CRM" в боковом меню
2. Вкладки:
   - **Клиенты** - база клиентов с контактами
   - **Заказы** - управление заказами и статусами
   - **Сделки** - воронка продаж и прогнозы
   - **Воронка продаж** - визуализация этапов

### Управление растениями
1. Каталог растений с фильтрацией по видам, здоровью, зонам
2. Добавление/редактирование/удаление растений
3. Детальная информация по каждому растению

### Задачи
1. Планирование работ по уходу
2. Отслеживание выполнения
3. Фильтрация по статусу

### Статистика
1. Графики распределения по видам, здоровью, зонам
2. Динамика роста
3. Возрастное распределение

## 🎨 Кастомизация

### Изменение цветовой схемы
Отредактируйте `src/index.css`:
```css
:root {
  --primary-color: #10b981; /* Основной цвет */
  --secondary-color: #3b82f6; /* Вторичный цвет */
}
```

### Добавление новых типов растений
Отредактируйте `src/types.ts` и `src/data.ts`

### Изменение бизнес-советов
Отредактируйте `src/components/BusinessAdviceView.tsx`
